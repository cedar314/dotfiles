# Global Agent Instructions

- Read applicable project and directory-specific `AGENTS.md` instructions.
- Understand relevant code and requirements before changing it. Keep changes within the requested scope.
- Prioritize correctness, readability, and maintainability. Reuse established patterns and utilities.
- Use descriptive names and comments for non-obvious logic and design decisions.
- Do not introduce significant dependencies, architectural changes, or breaking interfaces without approval.
- Run relevant tests, type checks, and linting. Never claim checks passed unless executed; report limitations.
- Do not commit, push, switch branches, or create worktrees unless requested.
- Never discard or overwrite unrelated user changes. Request approval before destructive operations.
- Never expose credentials or secrets.
- Review the diff before completing a task. Summarize changes, verification, and outstanding issues concisely.
- Do not modify `AGENTS.md` files unless explicitly requested.
